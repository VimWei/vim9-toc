Unified table of contents: folds + helptoc delegation
==============================================================================


1. OVERVIEW							*toc-overview*

The vim9-toc plugin provides one command, |:Toc|, which generates a
hierarchical table of contents in a popup window.

It is a unified entry point that delegates to the built-in |helptoc.txt| for
the structured filetypes helptoc already understands, and otherwise derives an
outline from Vim's own folding.  For buffers that have neither, an indentation
based outline is used as a last resort.

Resolution order (highest priority first):			*toc-resolution*

	1. helptoc native filetype	-> built-in :HelpToc
	2. custom collector		-> |toc-add-collector|
	3. Vim folding			-> |toc-folding|
	4. indentation fallback		-> |toc-indent|
	5. gentle message		-> nothing to outline

							*toc-:Toc*
							*toc#Open()*
							*toc#IsAvailable()*
The :Toc command takes no arguments.  It may be mapped for easier use, e.g.: >

	nnoremap <Leader>ht <Cmd>Toc<CR>
<
toc#Open() is the underlying function.  toc#IsAvailable() returns true when the
current buffer has a usable 'foldmethod' and popup support.

1.1 Popup mappings						*toc-mappings*

Inside the TOC popup:

	j / <Down>	select next entry
	k / <Up>	select previous entry
	J / K		same as j / k, and jump the main buffer to that entry
	gg / <Home>	select first entry
	G / <End>	select last entry
	H		collapse one level
	L		expand one level
	<C-D> / <C-U>	scroll down / up half a page
	<PageDown> / <PageUp>  scroll down / up a whole page
	z		redraw with the selected entry centered
	?		show / hide the help window
	<C-J> / <C-K>	scroll the help window down / up one line
	<Enter>		jump the main buffer to the selected entry and close
	<Esc>		close the popup without jumping

The popup title shows the current entry index and total entries, followed by
the current level and maximum level, e.g. " 2/3 (1/2)", with a
"press ? for help " hint on the right.

The level indicator (e.g. "| ") is highlighted with the |NonText| group and
the entry text with |Normal|, matching the look of helptoc.


2. FOLDING						*toc-folding*

For buffers whose 'foldmethod' is set (i.e. anything but empty or "manual"),
the outline is generated from the folds.  This means any filetype that ships a
folding ftplugin works out of the box, e.g. TOML, YAML, JSON, Git, and Vim
script (fold markers).

Supported 'foldmethod' values:

	expr	The 'foldexpr' is evaluated per line; a fold start is a line
		whose result begins with ">".  This correctly detects sibling
		folds at the same level.
	marker	Lines matching the opening 'foldmarker' are collected; the level
		comes from foldlevel().
	syntax/indent
		Fold starts are detected via foldlevel() transitions plus a
		per-level foldclosed() scan, so sibling folds at the same level
		are detected.


3. CUSTOM COLLECTORS					*toc-add-collector*

For formats whose headings are awkward to express as folds, register a custom
collector with |toc#AddCollector()|.  A collector is a function name (String)
taking no arguments and returning a |List| of Dictionaries, each with the keys:

	lnum	the line number of the heading (Number)
	lvl	the heading level, starting at 1 (Number)
	text	the heading text to display (String)

Example for reStructuredText underline-style headings: >

	function MyRstCollector() abort
	    let entries = []
	    for lnum in range(1, line('$'))
	        let line = getline(lnum)
	        if lnum < line('$') && line !~# '^\s*$'
	                \ && getline(lnum + 1) =~# '^[=-]\+\s*$'
	            let lvl = getline(lnum + 1) =~# '^=' ? 1 : 2
	            call add(entries, {'lnum': lnum, 'lvl': lvl, 'text': trim(line)})
	        endif
	    endfor
	    return entries
	endfunction
	call toc#AddCollector('rst', 'MyRstCollector')
<
A registered collector takes precedence over folding for its filetype.


4. INDENTATION FALLBACK					*toc-indent*

When no helptoc support, collector, or folding applies, an indentation based
outline is generated without touching the buffer's 'foldmethod'.  A line is
treated as a heading when the next non-blank line is indented deeper; its level
is `indent / 'shiftwidth' + 1`.  If even that yields nothing (e.g. an empty
buffer), a gentle message is shown.


5. CONFIGURATION					*toc-configuration*

	g:toc_level_indicator	String repeated per level below 1 in the popup.
				Default "| ".
	g:toc_use_helptoc	When true (default), delegate helptoc native
				filetypes to the built-in :HelpToc.

Example: >

	let g:toc_level_indicator = '| '
	let g:toc_use_helptoc = 1
<
